# 🐍 Curso de Introdução ao Python - Santander

Este repositório contém os exercícios, anotações e códigos desenvolvidos durante o curso **Introdução ao Python**, oferecido pelo **Santander**.

O objetivo deste projeto é documentar meu aprendizado prático e evolução nos conceitos fundamentais da linguagem Python.

---

## 📌 Conteúdo do Repositório

### 📁 1 - Introdução ao Python
* Primeiro programa em Python (`ola_mundo.py`).

### 📁 2 - Noções Básicas de Python
* **2.0 - Tipos de Dados Básicos:** Manipulação e conceitos de tipos de dados (`tipos_dados_basicos.py`).
* **2.1 - Variáveis:** Declaração e uso de variáveis (`variaveis.py`, `variaveis.txt`).
* **2.2 - Operadores:** Operadores aritméticos, lógicos e de comparação (`operadores.py`, `operadores.txt`).

### 📁 3 - Estruturas de Controle
* **3.0 - Estruturas Condicionais:** Uso de `if`, `elif` e `else` (`estruturas_condicionais.py`, `estruturas_condicionais.txt`).
* **3.1 - Loops:** Laços de repetição (`for`, `while`) e instruções de controle como `break`, `continue` e `pass` (`loops.py`).
